# B站直播录制（分享版）

一个面向 Windows 10/11 64 位的 B 站公开直播录制工具：每天到设定时间自动监测指定直播间，开播后用 ffmpeg 直接保存直播原流，按约 30 分钟分成 MKV 文件。

> 本工具只录制**公开直播**，不读取浏览器 Cookie，不绕过登录、付费或 DRM 限制，也不上传或删除录像。

## 一键安装

1. 打开本仓库的 **Releases** 页面，下载最新版本的 `B站直播录制_分享版_v1.0.0.zip`；
2. 解压到一个固定且可写的目录，例如 `D:\B站直播录制`；
3. 双击 `安装.bat`，按提示填写直播间房间号、主播名称、保存目录和每日启动时间；
4. 首次安装需要联网，安装程序会自动下载便携 Python、ffmpeg、yt-dlp（约 150 MB）。

安装完成后桌面会生成“启动 / 停止 / 查看状态 / 配置”四个快捷方式。

## 功能

- 支持任意 B 站公开直播间，默认立芯 `31462057`
- 默认每天 **21:30**（北京时间）通过 Windows 计划任务启动，登录时启动文件夹兜底
- 直播原流复制，不重新编码，MKV 格式，约 30 分钟分段
- 剩余磁盘空间低于 20 GB 自动暂停
- `配置.bat` 修改房间号、主播名称、保存目录、启动时间
- `更新解析器.bat` 更新 yt-dlp
- `卸载.bat` 只清理任务和快捷方式，不删除录像

## 系统要求

- Windows 10 或 Windows 11，64 位
- 首次安装需要网络
- 普通用户权限即可，不需要管理员权限
- 电脑需在每日启动时间保持开机并已登录当前 Windows 用户

## 开发说明

- `app/recorder.py`：每 30 秒检查直播间，开播后调用 yt-dlp 解析地址、ffmpeg 分段保存
- `app/control.ps1`：启动/停止/查看状态
- `app/scheduled-start.ps1`：每日计划任务和登录兜底
- `app/install.ps1`：一键安装、依赖下载、配置生成
- `app/dependencies.ps1`：便携 Python、ffmpeg、yt-dlp 的检测与下载
- 运行数据写入 `data/`，不要提交到 Git（已在 `.gitignore` 排除）
